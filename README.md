# Gaming Market

A simple gaming marketplace platform where users can:

- Buy and sell game accounts
- Trade in-game currency
- Manage wallet balance
- Create and promote products

## Features
- User registration
- Nickname system
- Wallet (top-up & withdraw)
- Product marketplace
- Admin system (verified badge)

## Tech Stack
- Node.js
- Express.js
- Simple frontend (HTML/CSS/JS)

## Note
This project is in development.
